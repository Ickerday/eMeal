# eMeal
### An app to make a meal out of some stuff you have in your fridge. 

- Running: 
1. Make sure to install NuGet packages and migrate the database.
2. That should be it!

- Development:
1. Install NPM Task Runner from the extension store.
2. The runner should pick up tasks from package.json along with when to run them. 
3. Whenever you modify the code, Sass and TypeScript watchers should recompile the it on-the-fly.
